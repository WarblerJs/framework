# Code of Conduct

WarblerJS contributors are expected to keep technical collaboration respectful, specific, and architecture-focused.

## Standards

- Be precise and constructive in technical feedback.
- Assume architectural constraints exist for a reason until the documentation says otherwise.
- Keep disagreements focused on evidence, code, tests, and specifications.
- Do not use harassment, threats, personal attacks, or discriminatory language.

## Scope

This applies to repository issues, pull requests, documentation, examples, release discussions, and project communication channels.

## Enforcement

Project maintainers may moderate, edit, close, or remove contributions that violate these standards. Severe or repeated violations may result in blocked participation.
